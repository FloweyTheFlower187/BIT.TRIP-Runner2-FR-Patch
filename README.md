# BIT.TRIP Runner2 FR Patch
# An fanmade FR patch for BIT.TRIP RUNNER2 

This version does not include french special characters (é,è,à,ç,etc...)

# EN >>>>>> FR

    STEPS :

    1. Make a copy of your game 

    2. Install the .zip in the releases tab

    3. Find the directory of your original runner2.exe (not modded version) 

    4. Make sure the original version of runner2 is nammed "runner2.exe"

    5. Launch "fr_patch.py" with python

    6. Choose the directory of your original runner2.exe file when prompted

    7. Wait until you see "Patch terminé !"

    6. Enjoy :)

# FR >>>>>> EN

    STEPS :


    1. Find the directory of your copy of the original runner2.exe (not modded version) 

    2. Replace the copy (not modded version) by the modded version (french patched)

    3. Your game is now in english

# Tools Used

to_dds.py : Transform the .aetex files to .dds files (Direct Drawing Surface)

update_aetex.py : Transform the dds files to .aetex files to make it work with runner2

HxD editor : Change the text and change the hex values

Ghidra : Reverse engineering

# TROUBLESHOOTING

    Problem : The .py dont show anything
    
    Fix : Make sure you have the latest python version installed and that you open it via the python terminal

    Problem : xdelta3 not found

    Fix : Make sure you installed xdelta3.exe in the same directory as the "fr_patch.py"
